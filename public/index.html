          Dokumentasi REST API & Konfigurasi MCP
        

        
Integrasikan engine ini ke dalam aplikasi pihak ketiga, Claude Desktop, atau Cursor AI.

      

      

        
        
        

          

            1. Konfigurasi Client MCP (Claude Desktop / Cursor):
            
          

          
{
  "mcpServers": {
    "media-converter": {
      "command": "node",
      "args": ["/app/projects/media-converter-mcp/dist/index.js"]
    },
    "ats-resume": {
      "command": "node",
      "args": ["/app/projects/ats-resume-mcp/dist/index.js"]
    }
  }
}

        


        
        

          

            2. Contoh cURL Audit ATS Resume:
            
          

          
curl -X POST http://localhost:8080/api/ats/review \
  -H "Content-Type: application/json" \
  -d '{"text": "Alex Pratama\nalex@tech.io\nSummary: Senior Software engineer..."}'

        


        
        

          

            3. Contoh cURL Konversi Gambar ke WebP:
            
          

          
curl -X POST http://localhost:8080/api/media/convert-image \
  -F "file=@foto.png" \
  -F "format=webp" \
  -F "quality=80" \
  --output foto.webp
